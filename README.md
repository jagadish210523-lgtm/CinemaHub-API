Cinema Hub API

This repository contains my Cinema Hub API project, built using FastAPI, Python, and MySQL. The project brings together backend development concepts through a cinema booking system.

Concepts Practiced
Building REST APIs with FastAPI
Organizing endpoints using APIRouter
Request validation using Pydantic
Connecting FastAPI with MySQL
Database operations using SQLAlchemy
User registration and authentication
JWT-based authentication
Handling HTTP errors and responses
Organizing a backend project into separate modules
Features Implemented
User Authentication

Implemented user registration and authentication as part of the backend.

Database Integration

Connected the FastAPI application to a MySQL database to work with persistent data.

API Routing

Organized API endpoints using separate routers to keep the application structured and maintainable.

Request Validation

Used Pydantic models to validate incoming request data.

Cinema Booking System

Developed the backend as a foundation for cinema-related operations, including movies, theatres, and bookings.
